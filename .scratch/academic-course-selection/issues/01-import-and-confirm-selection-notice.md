# 01: 导入并确认选课通知

**What to build:** 用户可以从学校官网或 WebVPN 通知链接、粘贴的通知正文、人工口述信息创建一个选课窗口。系统提取选课类型、学期、适用对象、开放时间、截止时间、入口提示和限制条件，但只有用户核对并确认后，该窗口才能驱动后续教务查询。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 支持通知链接、通知正文和人工录入三种来源，并保留来源、获取时间和人工/官网标识。
- [x] 提取结果缺少学期、选课类型或时间范围时明确标记待补充，不静默猜测。
- [x] 未经用户确认的选课窗口不能触发教务查询、计划武装或提交操作。
- [x] 通知正文和确认结果仅保存在本机，不上传账号、身份或学业数据。

## Comments

已实现本地通知模型、字段提取、人工补全与确认、JSON 本地保存，以及 Flask 页面导入/确认流程。当前链接字段会随通知正文保存；需要认证的通知正文仍由用户在浏览器中完成登录后粘贴，未接入教务接口。
