# 02: 定位并只读探索对应教务选课入口

**What to build:** 用户选择一个已确认的选课窗口后，工具通过现有可视浏览器会话进入对应教务菜单，确认匹配的选课轮次，并只读呈现能够获得的课程班、教师、时间、容量和已选状态。工具优先识别页面实际使用的网络接口，为后续稳定读取建立经过脱敏的请求契约。

**Blocked by:** 01/导入并确认选课通知.

**Status:** ready-for-agent

- [x] 能区分登录失效、入口不可达、轮次未开放、无匹配轮次和真实空结果。
- [x] 探索期间不发送选课、退课、保存或提交请求，也不点击会改变选课状态的控件。
- [x] 记录接口方法、参数形状和响应字段时移除 Cookie、令牌、学号、姓名及其他身份信息。
- [ ] 稳定读取优先使用与浏览器共享认证状态的请求上下文；接口不可确认时保持只读并报告阻塞，不猜测提交契约。
- [x] 通过固定响应样本验证课程班字段解析和数据不完整状态。

## Comments

已实现只读探索命令：认证后自动进入新教务系统“学生选课”菜单，仅查询确认通知和学生画像匹配的类别。程序直读已验证的 `POST /xsxk/queryXsxkList`，自动翻页并合并结果；未捕获到可确认接口时报告 `interface_unconfirmed`，不会误报为空，也不会猜测或重放提交请求。

补充自动发现与认证基础设施：自动导航在目标页面前只检查主页面菜单树，记录点击前后的完整可见 DOM 控件与新增二级菜单，避免把 iframe 内“备选课程/已选课程”误判为顶部导航。新增 Windows DPAPI 凭据配置和 Playwright storage state 复用；凭据仅允许填写到 HITWH WebVPN 的 HTTPS CAS 登录路径。

2026-08-25 真实验证通过：Playwright Chromium 经 EasyConnect 失效状态回退、CAS 自动登录和新教务统一认证中间页，严格按“学生选课 → 文化素质核心”进入 `/xsxk/queryXsxk?pageXklb=szhx`。已保存每次点击前后截图、完整 DOM 差异及只读表单契约；确认页面使用 `POST` 查询，筛选字段包括 `pageXnxq`、`pageKkxiaoqu`、`pageKkyx`、`pageKcmc`。页面显示该轮选课时间为 2026-08-29 08:30 至 10:30，当前空表不能判定为无课程。

2026-08-25 分页验证通过：2025 级画像对应体育、创新研修、创新实验、创新创业、文化素质核心、外专业课程，共读取 17 页、303 条课程记录；所有类别分页完整，拦截请求 0 条。
