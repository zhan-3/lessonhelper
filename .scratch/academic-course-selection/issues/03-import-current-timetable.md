# 03: 导入并展示当前课表

**What to build:** 用户可以导入学校导出的当前学期课表，并在本地页面看到按星期和节次排列的正式课程。课表保留教学周和单双周信息，成为后续候选课程时间检查的可靠占用快照。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [x] 支持学校当前模板的 XLS 和 XLSX 文件，并解析学期、星期、节次、教学周及单双周。
- [x] 文件结构不匹配、必要时间字段缺失或学期不一致时拒绝启用该课表并说明原因。
- [x] 导入结果在本地课表页面可视化，重复导入前展示将被替换的快照信息。
- [x] 原始课表和规范化结果只保存在本机，不包含登录状态或 Cookie。

## Comments

已实现 XLS/XLSX 解析、学期校验、时间字段规范化、JSON 快照和本地课表展示；已有快照需要显式勾选后才能替换。解析器同时支持规范化列式表和学校个人/班级课表的星期列网格，已用 docs 下的个人课表与班级课表各解析验证一次；不符合模板的文件会拒绝启用。
