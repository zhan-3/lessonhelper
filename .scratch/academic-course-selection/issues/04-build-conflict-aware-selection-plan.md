# 04: 呈现可选课程并生成候选计划

**What to build:** 用户打开一个有效选课窗口时，可以看到教务系统实时返回的对应课程班，并将感兴趣的课程班加入灰色候选计划。系统结合当前课表和毕业进度说明候选可能满足的要求，同时阻止存在课表时间冲突的候选进入执行队列。

**Blocked by:** 02/定位并只读探索对应教务选课入口; 03/导入并展示当前课表.

**Status:** ready-for-agent

- [ ] 课程班展示包含课程身份、学分、教师、时间、容量、选课类型、数据时间和已选状态中实际可获得的字段。
- [ ] 读取课程班时优先调用已确认的认证接口，不依赖脆弱的按钮和表格层级；接口不可用时明确降级状态。
- [ ] 星期、节次和教学周存在交集时标记课表时间冲突，并禁止该候选进入可执行计划。
- [ ] 只有明确类别映射的候选才展示潜在进度贡献；未映射课程保持待归类，不使用关键词猜测。
- [ ] 灰色候选不计入已确认完成或预计完成，且课程班数据不完整时不把未知容量解释为零。
