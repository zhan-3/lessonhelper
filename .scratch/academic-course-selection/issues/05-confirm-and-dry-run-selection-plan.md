# 05: 确认并演练选课计划

**What to build:** 用户可以排列候选优先级、建立备选组，并在提交前核对选课通知、当前课表、课程班和登录状态的完整快照。dry-run 走完读取、定位和请求准备流程，但保证不会发送任何改变选课状态的请求。

**Blocked by:** 04/呈现可选课程并生成候选计划.

**Status:** ready-for-agent

- [ ] 确认快照包含选课窗口、课程班身份、优先级、备选组、课表版本和课程班数据时间。
- [ ] 学期不一致、窗口尚未开始或已经结束、课表时间冲突、数据过期时不能武装任务。
- [ ] dry-run 使用与真实执行相同的读取和请求构造路径，但在发送状态变更请求之前由可测试 seam 截断。
- [ ] 用户可以在本地页面清楚看到“未武装、已武装、dry-run 完成、不可执行”状态。
- [ ] 固定接口样本和假 Adapter 能证明 dry-run 不会调用提交操作。
