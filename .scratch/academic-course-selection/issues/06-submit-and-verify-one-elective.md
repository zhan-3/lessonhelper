# 06: 受控提交一门课程并核验

**What to build:** 用户对一门候选课程明确武装并启动后，工具在有效选课窗口内执行一次选课操作，并通过重新读取已选课程确认最终结果。实现优先直接调用浏览器已经观察并验证过的选课接口，浏览器页面只承担登录、必要令牌建立和兼容兜底。

**Blocked by:** 05/确认并演练选课计划.

**Status:** ready-for-agent

- [ ] 只有当前确认快照仍有效且用户明确启动时，执行器才允许发送状态变更请求。
- [ ] 接口提交复用浏览器认证上下文和页面产生的必要防伪信息，不把 Cookie 或令牌复制到独立配置中。
- [ ] 未确认真实请求契约时禁止猜测接口；需要 DOM 兜底时使用可见浏览器并沿用相同确认和核验规则。
- [ ] 一次启动最多提交一门已确认课程；响应不明确时停止，不盲目重复请求。
- [ ] 成功必须由已选课程读取结果确认，不能只依赖 HTTP 200、按钮点击或成功弹窗。
- [ ] 登录失效、验证码、限流、窗口失效、容量变化或课程班身份变化时停止并展示可诊断状态。
