# 07: 执行多课程优先级与异常恢复

**What to build:** 用户可以在一个已确认的选课窗口内按顺序处理多个候选和备选教学班。工具复用已经核验的单课程执行能力，达到用户设定的课程数或备选组目标后立即停止，并在中断后留下可以检查但不会自行续跑的本地状态。

**Blocked by:** 06/受控提交一门课程并核验.

**Status:** ready-for-agent

- [ ] 候选严格按用户确认的优先级执行，组内成功一项后其余备选失效。
- [ ] 达到目标课程数、目标课程学分或所有候选终结条件后停止，不继续多选。
- [ ] 轮询遵守配置的最低间隔和服务端限制；验证码、限流或连续异常不会触发加速或规避行为。
- [ ] 每次尝试、结果核验和停止原因写入不含身份凭据的本地事件日志。
- [ ] 进程崩溃或浏览器关闭后可以恢复计划和只读状态，但再次提交前必须重新确认并武装。
