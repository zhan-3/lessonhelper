# 08: 收紧并抽出只读教务网关

**What to build:** 学生继续通过现有只读命令查询通知匹配的待选课程，但查询范围、轮次识别、分页和课程教学班解析由一个稳定的教务网关负责。查询结果能够可靠表达已选状态和各种空结果，不再把含身份或令牌的原始页面保存为应用数据。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 现有已确认通知和 2025 级学生画像仍能生成严格查询白名单，并读取白名单中全部类别和分页。
- [ ] 同一类别存在多个选课窗口时，结果能够匹配具体窗口，并区分未开放、无匹配轮次、真实空结果、登录失效、接口未确认和读取不完整。
- [ ] 课程教学班保留课程身份、教学班身份、教师、时间、容量及来源可提供的已选状态；未知状态不被写成 false 或零。
- [ ] 课程类别代码、通知别名、页面名称和导航优先级由一个规范定义驱动，新增类别不需要在多个独立映射中重复维护。
- [ ] 观察任务继续阻断选课、退课、保存、注册及疑似写请求，不猜测任何提交契约。
- [ ] 正常查询和诊断不保存原始 HTML；结构化请求与错误信息移除 Cookie、令牌、学号、姓名和其他身份字段。
- [ ] 脱敏固定样本覆盖分页、复合容量、已选状态、具体窗口匹配和所有结果状态，全量现有测试继续通过。
