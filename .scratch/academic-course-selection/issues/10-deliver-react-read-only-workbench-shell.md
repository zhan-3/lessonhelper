# 10: 交付 React 只读工作台外壳

**What to build:** 学生使用一个本地工作台查看 SQLite 中的学生画像、通知和教务快照。正式运行仍只需要一个启动命令，页面加载只读取本地数据，不会因为打开或刷新浏览器页面而访问学校系统。

**Blocked by:** 09/将现有工作区迁移为 SQLite 快照.

**Status:** ready-for-agent

- [ ] Flask 通过稳定 JSON API 提供画像、通知、快照和应用状态，并在正式模式托管构建后的 React 页面。
- [ ] API 契约可生成 TypeScript 类型，前端不手写一套可能漂移的任务和快照模型。
- [ ] React 工作台展示当前学期、画像、已确认通知、快照来源、数据截至时间和适用性。
- [ ] 页面初次加载和普通刷新只读取 SQLite，不启动 Playwright、不检查登录、不发送学校网络请求。
- [ ] 开发模式支持前后端独立热更新，正式使用时用户无需安装或运行 Node。
- [ ] 服务仅监听 loopback；改变本地状态的 API 具备同源和 CSRF 防护基础。
- [ ] Flask API 测试和前端测试从用户可观察行为验证数据呈现、空工作区和不适用快照状态。
