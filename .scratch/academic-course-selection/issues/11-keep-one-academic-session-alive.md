# 11: 连接并常驻唯一教务会话

**What to build:** 学生从工作台点击连接后，只启动一个 Playwright 自带的可见 Chromium，并在本地服务运行期间持续复用同一教务会话。认证需要人工介入或浏览器被关闭时，页面给出真实状态而不是中途退出或偷偷切换浏览器。

**Blocked by:** 08/收紧并抽出只读教务网关; 10/交付 React 只读工作台外壳.

**Status:** ready-for-agent

- [ ] 打开本地快照不会启动浏览器；首次连接或受保护任务才惰性启动 Playwright bundled Chromium。
- [ ] Playwright、浏览器上下文和页面由唯一专用工作线程创建和使用，HTTP 请求不直接操作 Playwright 对象。
- [ ] 会话复用已有 storage state，并只在精确的大学 CAS HTTPS 凭据页使用 DPAPI 凭据恢复认证。
- [ ] 前端能够区分未连接、连接中、等待认证、已连接和已断开；等待认证时允许用户在可见浏览器中完成操作。
- [ ] 正常连接成功后浏览器保持到服务退出，不因一个请求或一次发现流程结束而关闭。
- [ ] 程序不自动回退到系统 Chrome；浏览器被用户关闭或崩溃时会话转为断开，下一次任务可以重新建立。
- [ ] 工作区级单实例约束确保重复启动不会产生第二个服务或浏览器，崩溃遗留的失效锁可以安全接管。
- [ ] 使用假的教务网关从 JSON API 验证惰性连接、状态变化和关闭生命周期，且不依赖真实学校网络。
