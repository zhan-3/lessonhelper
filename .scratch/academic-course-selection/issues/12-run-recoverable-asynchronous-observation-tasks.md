# 12: 运行可恢复的异步观察任务

**What to build:** 学生可以从工作台提交、查看和取消教务观察任务，而不让长时间学校请求阻塞页面。任务共享唯一教务会话、按顺序运行，并在认证暂停或普通取消后保持会话可复用。

**Blocked by:** 11/连接并常驻唯一教务会话.

**Status:** ready-for-agent

- [ ] 提交任务立即返回任务身份，前端能够轮询排队、连接、等待认证、读取、成功、失败、请求取消和已取消状态。
- [ ] 所有教务任务串行运行；等价的待处理刷新自动合并，并向重复请求返回同一个可观察任务。
- [ ] 排队任务可立即取消，运行任务在当前请求结束后、下一页或下一阶段开始前协作式停止，不关闭健康浏览器。
- [ ] 自动认证无法继续时任务最多等待用户十分钟；认证完成后同一任务继续，超时只结束刷新尝试。
- [ ] 浏览器断开或失去响应产生可诊断任务结果；后续任务能够按会话策略重建，而不是让工作线程永久失效。
- [ ] 任务进度支持操作名称、类别、页码和脱敏消息，错误页面和敏感身份信息不进入任务历史。
- [ ] 观察任务从任务入口到网络守卫均禁止选课状态写入。
- [ ] Flask API、真实临时 SQLite 和确定性假网关的端到端测试覆盖串行、合并、取消、等待认证、恢复和失败状态。
