# 13: 刷新完整待选课程快照

**What to build:** 学生从工作台刷新当前画像和已确认通知允许的待选课程，看到每个类别和分页的进度，并只在全部读取成功后获得新的适用快照。任何部分失败都会保留上一份完整列表和明确的失败时间。

**Blocked by:** 12/运行可恢复的异步观察任务.

**Status:** ready-for-agent

- [ ] 刷新只查询当前画像、学期和已确认通知版本生成的查询白名单，排除退课、申请、人工办理及其他年级窗口。
- [ ] 生产教务网关通过已验证的只读课程查询读取所有白名单类别和服务端分页，不依赖点击选择或保存控件。
- [ ] 前端实时显示类别及页码进度，并在完成后展示课程代码、名称、学分、教师、时间、校区、院系、对象、要求、容量和可获得的已选状态。
- [ ] 课程身份与学期内课程教学班身份分别保存；缺失任务号时采用规范组合身份，复合容量不被压成虚假总量。
- [ ] 未开放、无匹配轮次、真实空结果、登录失效、接口未确认和读取不完整保持不同状态。
- [ ] 只有所有类别和分页成功才在单一事务中发布新快照；失败尝试保留旧快照并显示脱敏错误。
- [ ] 快照绑定画像版本、学期和通知版本，30 分钟后标记过期，并保留最近二十份成功结构化历史。
- [ ] 正常刷新不保存原始 HTML，不发送任何选课写请求；固定样本、假网关和真实临时数据库测试覆盖完整与失败路径。
