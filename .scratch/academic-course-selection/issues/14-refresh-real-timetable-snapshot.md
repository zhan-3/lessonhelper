# 14: 刷新真实课表快照

**What to build:** 学生从工作台直接读取教务系统中的当前课表并看到基础周视图，不再必须手工导出文件。学校接口暂时不可用时，现有 XLS/XLSX 导入仍可产生来源明确的用户导入快照。

**Blocked by:** 12/运行可恢复的异步观察任务.

**Status:** ready-for-agent

- [ ] 在只读浏览器会话中确认真实个人课表查询契约；接口不能确认时报告阻塞，不猜测参数或点击改变状态的控件。
- [ ] 一次刷新完整读取课程身份、名称、星期、节次、教学周、单双周、地点及来源可提供的教师信息。
- [ ] 完整读取后在单一事务中发布绑定画像版本和学期的课表快照；任何缺页、解析失败或认证错误保留旧快照。
- [ ] 课表快照 24 小时后标记过期，并保留最近二十份成功结构化历史。
- [ ] 工作台按星期和节次展示真实课表及数据截至时间、来源和刷新状态。
- [ ] XLS/XLSX 导入继续校验学期和时间字段，并明确标记为用户导入快照，不冒充实时接口读取。
- [ ] 模糊、缺失或待定时间被表示为冲突未知，而不是空闲。
- [ ] 脱敏固定接口样本、现有课表文件样本、假网关和临时 SQLite 测试覆盖成功、回滚及导入退路。
