# 15: 发现并确认官方选课时间通知

**What to build:** 学生可以主动检查学校官方本科教务通知栏目，只看到类似“各类课程选课时间安排”的候选通知。通知正文发生变化时，工作台展示新版本及差异，只有学生确认的具体版本才能改变查询白名单。

**Blocked by:** 10/交付 React 只读工作台外壳.

**Status:** ready-for-agent

- [ ] 用户点击检查时只扫描配置的官方本科教务通知来源，标题含普通“选课”关键词但不属于综合时间安排的文章不会被误用。
- [ ] 候选通知解析学期、选课窗口、适用年级、类别、操作和办理方式；字段不完整时可供查看，但不能驱动教务查询。
- [ ] 公开来源无需启动教务浏览器；确实需要 WebVPN 时复用已有教务会话，不创建额外浏览器。
- [ ] 同一来源正文变化会创建不可变新通知版本并展示差异，不覆盖或静默替换当前确认版本。
- [ ] 候选通知必须由用户明确确认后才能生成新的查询白名单，确认前不改变当前规划或适用快照。
- [ ] 默认不轮询；可选七天检查只在工作台本来就在运行时触发，不唤醒程序、不启动浏览器、不主动保活。
- [ ] 手工粘贴官方链接和正文继续作为发现失败时的退路，并遵循相同版本及确认规则。
- [ ] 固定官方通知样本和 API/UI 测试覆盖严格匹配、多窗口解析、内容版本变化、确认和无副作用候选状态。
