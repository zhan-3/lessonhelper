# 16: 叠加候选课程并形成只读选课规划

**What to build:** 学生以真实周课表为中心查看感兴趣的待选课程班，直观看到与当前课程、其他候选以及未知时间之间的关系，并建立课程目标和教学班偏好。规划只保存在本地，不会提交选课。

**Blocked by:** 13/刷新完整待选课程快照; 14/刷新真实课表快照.

**Status:** ready-for-agent

- [ ] 桌面和横屏显示七日周视图，手机竖屏默认单日滑动视图并可切换横向滚动整周视图。
- [ ] 当前课表始终铺开，用户聚焦或勾选的候选教学班以半透明灰色叠加，未选择候选保留在列表中。
- [ ] 星期、节次、教学周和单双周存在交集时标记与当前课表的红色冲突；候选之间冲突使用橙色区分。
- [ ] 时间缺失、待定或无法解析的教学班显示冲突未知，并在用户明确确认前不能成为可执行偏好。
- [ ] 用户可以建立有顺序的课程目标，并在每个目标内排列多个可接受教学班，课程优先级不与教学班偏好混用。
- [ ] 规划绑定适用课表和待选课程快照；快照过期或画像、学期、通知版本不匹配时明确阻断“规划已就绪”状态。
- [ ] 候选列表展示未开始、开放中和已结束窗口，但只有开放中窗口被标记为未来可能执行。
- [ ] 所有规划操作只改变本地数据，不发送教务写请求；API 和前端测试覆盖冲突、冲突未知、响应式视图及双层偏好。
