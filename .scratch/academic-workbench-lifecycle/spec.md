# Academic workbench lifecycle

工作台是长期运行的本地单用户工具，但默认离线启动。远程认证和查询仅由用户操作触发。任何时刻只允许一个远程任务；任务必须具有明确超时和终态。

教务会话必须通过固定受保护业务页验证，不能由页面标题或 loginCAS URL 推断。待选课程按学生画像版本、学期、通知版本和查询契约版本缓存；上下文一致时使用本地完整快照。选课前只重新验证目标类别、来源页和 rwh，取得新 token 后单次提交，不自动重试或尝试其他教学班。

升级时保留学生画像、已确认通知、登录配置及至多一份课表参考；删除不兼容的待选课程、毕业进度、规划和任务数据。新执行历史只保存脱敏结果。
