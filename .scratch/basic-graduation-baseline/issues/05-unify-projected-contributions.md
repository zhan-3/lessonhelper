# 05: 统一本学期、队列和申报的预计贡献

**What to build:** 学生在同一学分面板中查看已确认完成、本学期已选、队列预览和用户申报产生的不同贡献，并获得统一去重后的预计缺口。队列只参与本地规划，不扩展或触发抢课执行。

**Blocked by:** 03/申报成绩接口未覆盖的认定学分；04/补充课程标签并核验外专业课程体系

**Status:** ready-for-agent

- [ ] 每项要求分别展示最低要求、已确认完成、本学期已选、队列预览、用户申报、已确认缺口、预计缺口和待核验项。
- [ ] 相同课程的贡献优先级为已确认完成高于本学期已选、高于队列预览，较低层级不会重复增加学分。
- [ ] 用户申报与明确关联的课程或认定事项去重；无法确认重叠时保留申报性质和核验提示。
- [ ] 同一事实在一个要求总额中最多计算一次，但可以同时贡献父级合计和必要子约束。
- [ ] 创新创业和社会实践在组合要求中合并去重，不把子项与组合项再次相加。
- [ ] 用户申报、手动课程标签和队列变化只在本地重算，不要求重新访问学校。
- [ ] 全部阈值、映射、状态和贡献由统一计算结果提供，界面不保留另一套基线数字或独立归类算法。
- [ ] 预计达到最低值只显示预计可满足，不改变已确认条件状态；未知条件继续阻止整体已确认满足。
- [ ] 文化素质、D 类、四史以及所选外专业体系的父子关系和贡献解释清晰可追溯。
- [ ] 没有待选课程快照或队列为空时，已确认进度、申报和全部基础要求仍正常展示。
- [ ] 规划队列不会因本任务增加自动提交、自动重试或任何真实选课行为。
- [ ] 公开行为测试覆盖跨来源重复、组合要求、标签预计贡献、队列变化和前后端计算口径一致性。
