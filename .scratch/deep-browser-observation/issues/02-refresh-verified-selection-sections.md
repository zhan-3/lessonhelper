# 02: 通过已验证读取刷新待选课程班

**What to build:** 学生刷新待选课程班时，系统使用持久化教务会话和已验证读取规则完成所有查询白名单类别及分页，只在整次读取完整时发布新的教务快照。

**Blocked by:** 01/通过新观察接缝发布带轨迹的个人课表事实

**Status:** resolved

- [x] 待选课程班刷新通过类型化观察请求和结果运行，并复用现有 Chromium 与教务会话。
- [x] 查询只覆盖已确认选课窗口形成的查询白名单，不扩大允许读取的课程类别。
- [x] 所有预期类别和分页完整读取后才能返回可发布结果。

- [x] 教务请求轨迹覆盖认证、入口加载和所有类别及分页请求。
