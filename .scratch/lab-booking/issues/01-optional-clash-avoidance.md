# 01: 撞课避让作为可选模式

**Status:** ready-for-human (需求已记录，尚未实现高级抢课配合)

## 背景

`lab-booking` 目前默认按个人课表避让冲突。实际使用中，大部分正课可以不去，
撞课并非必须避免；只有少数"高要求"场景（例如必须全勤、或需要提前进入抢占名额）
才需要严格避让。

## 需求

- [x] 避让改为显式开关：`--avoid none|timetable|all`，默认 `timetable`。
- [ ] 支持"高要求模式"：把课表、其它实验中心已约实验、跨课程实验一起作为占用，
      并在规划层给出无冲突方案。
- [ ] 与"提前进入"等抢课时机的配合需要单独设计：只允许在用户已建立的合法会话内
      进行定时、单次提交；不得绕过开放时间、资格名单或身份校验。
- [ ] 记录当时使用的占用来源与快照时间，便于事后复核对齐。

## 边界

不实现：伪造身份或参数、重放受限请求、绕过资格或时间窗、代他人操作。
