# 04: 工作台集成实验预约

**Status:** ready-for-agent

## 目标

在工作台内查看实验状态、规划与执行，复用 `course_selection/lab_booking.py` 的核心逻辑，
不在前端重写一套阈值或归类算法。

## 需求

- [ ] 工作台展示每个中心的：应用可用状态、已约实验、完成窗口、剩余待约项。
- [ ] 规划视图并列显示"课表占用"与"已约实验占用"，同刻冲突作为提醒而非自动改写。
- [ ] 执行入口复用既有限制：显式确认令牌、每门一次、提交前重读空位、不重试。
- [ ] 失效令牌/证书时展示明确的重新进入指引，不静默失败。
- [ ] 本地只存时段、状态与结果；不存 Cookie、令牌或响应正文。
- [ ] 与既有快照、画像隔离、重置逻辑保持一致：清除个人工作区一并清除武装目标与结果。
